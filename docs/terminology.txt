# Terminology

Terms that must be used consistently across the codebase and documentation
(SPEC-ADDENDUM-SSOT S7, check C18). Format: one `canonical = forbidden1, forbidden2`
line per term.

chat = group chat, room
supergroup = super group, super-group
member = user (when referring to a chat participant role)
restrict = mute (when describing the Telegram right `can_restrict_members`)
denylist = blacklist
allowlist = whitelist
update = event (for Telegram `Update` objects)
admin = administrator (spell out in prose, `admin` in code)
sudo = superuser, root
